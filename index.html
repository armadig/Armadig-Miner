What it does

Pearl and Quantus

Mines PRL and QTC. Pass two wallets on the command line and it works out which is which.

One window, all cards

One process runs every GPU in the rig, each card on the coin that pays it best.

Profit mode

Enter your electricity tariff and currency. The miner picks the most profitable power limit for each tariff zone.

Tuned per card

A one-time per-card tune on first start, cached for later runs.

Start

armadig  <pearl-wallet>  <quantus-wallet>

Fee

CoinDev fee
Pearl (PRL)0.75 %
Quantus (QTC)0.75 %

The fee is work-based, written into the build, and shown in the start banner. It does not slow the mining down.
