Quick start

From download to mining in a few minutes.

1. Download and check

Get the archive from Releases. It holds windows/armadig-miner.exe, linux/armadig-miner, armadig.conf, start_armadig.bat and SHA256SUMS.txt. Check the files before you run them.

certutil -hashfile windows\armadig-miner.exe SHA256      (Windows, cmd)
sha256sum -c SHA256SUMS.txt                               (Linux)

The result must match SHA256SUMS.txt. If it does not, do not run the file.

2. Requirements

  • NVIDIA: a driver for CUDA 12.9 or newer (R575+). No CUDA toolkit needed.
  • AMD on Windows: the AMD Adrenalin driver. AMD on Linux: the ROCm / HIP runtime and membership of the video or render group.
  • Windows x64, or Linux x86-64 with glibc 2.17 or newer.
  • Start the miner as administrator (Windows) or root (Linux) to use the power-limit search. Without it the miner still mines, and one red line says so.

3. See your cards

armadig-miner.exe --list

Shows each card and what would run on it. No GPU work is started.

4. Start

Simplest: your two payout addresses, nothing else (Pearl and QTC, either order; one address mines that coin only). The miner picks the fastest approved pool for each coin and the better-paying coin for each card.

armadig-miner.exe YOUR_PEARL_WALLET YOUR_QTC_WALLET

One coin, your own pool:

armadig-miner.exe mine --algo pearl --pool POOL_HOST:PORT --wallet YOUR_PEARL_WALLET --worker WORKER
armadig-miner.exe mine --algo qtc   --pool POOL_HOST:PORT --wallet YOUR_QTC_WALLET   --worker WORKER

Both coins with your own pools:

armadig-miner.exe mine --pearl-pool POOL_HOST:PORT --pearl-wallet YOUR_PEARL_WALLET ^
  --qtc-pool POOL_HOST:PORT --qtc-wallet YOUR_QTC_WALLET --worker WORKER

Only some cards: add --gpu 0 or --gpu 0,2 (indexes from --list). Keep the worker name neutral (w1, w2): pools show it publicly.

No wallet? Started with no valid wallet anywhere, the miner runs test mining for the developer: all work goes to the developer, a red warning says so at the start and every 60 s. Any valid wallet turns it off at once.

5. The first run tunes each card

The first time a card runs a kernel, the miner tunes it while mining: at most about 20 minutes per card and kernel, usually much less. Shares found during the tune count normally. The result is cached in autotune.json, so later starts are instant. See Tuning.

Launcher and config file

Windows: open start_armadig.bat in Notepad, put your addresses in PEARL_WALLET and QTC_WALLET (one is enough), save, double-click. The window stays open after the miner exits.

Config file: put your address after wallet = in armadig.conf, set your tariff and power supply, and armadig-miner.exe mine is enough. All keys: Config file.

Linux

sha256sum -c SHA256SUMS.txt
chmod +x linux/armadig-miner
./linux/armadig-miner YOUR_PEARL_WALLET YOUR_QTC_WALLET
# AMD: if the HIP runtime is not found
LD_LIBRARY_PATH=/opt/rocm/lib ./linux/armadig-miner YOUR_PEARL_WALLET YOUR_QTC_WALLET

HiveOS and RaveOS

The Linux program runs on HiveOS as a custom miner (no ready-made package yet). Put the binary in a custom miner folder, choose Miner = Custom in the Flight Sheet and write an h-run.sh that starts it. HiveOS statistics are not integrated: read the rate from the miner's console or a --log file. Use the Stop button; a hard kill can leave a memory clock lock behind, and the next start recovers it.

#!/usr/bin/env bash
cd "$(dirname "$0")"
exec ./armadig-miner mine --algo pearl --pool "$CUSTOM_URL" --wallet "$CUSTOM_WALLET" \
  --worker "${WORKER_NAME:-w1}" --log /var/log/miner/armadig/armadig.log

You can also pass everything in ONE line without any file, in the flight sheet's "Extra config arguments": see the one-line form.

Pool choice

Without --pool the miner mines on the fastest approved pool. Choose the pool region nearest to the rig: the bottom bar shows the latency as pool NN ms, and latency costs paid rate, more on QTC because its jobs are shorter.
