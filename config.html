Config file: armadig.conf

Only a wallet is needed. Write each setting on one line, the way you like.

The shipped file

# armadig.conf
wallet =
pool = any
tariff = 23-7 4.33, 7-23 9.63 rub   # EUR / Germany: tariff = 23-7 0.30, 7-23 0.38 eur
psu = gold, 750w

Put your address after wallet =, set your tariff and power supply, save. Then armadig-miner.exe mine is enough.

A fuller example

wallet = YOUR_PEARL_WALLET, YOUR_QTC_WALLET
pool = qtc my.pool.net:7049, pearl kryptex
worker = rig1
tariff = 23-7 4.33, 7-23 9.63 rub
psu = gold, 1200w
power = auto
power_max_loss = 10%
fees = pool 1%, sell 0.2%
gpu1 = qtc, my.pool.net:7049
mem-control = none

All keys

Syntax

  • One setting per line: key = value or key: value. Keys ignore case, and - / _ are the same. # starts a comment, also after a value.
  • The file may be UTF-8 or, line by line, Windows-1251.
  • The command line wins over the file. The last line of a key wins.
  • The file is looked for next to the program, in the folder you start it from, and in the package folder above windows/ and linux/. The start block names the file it uses (config: <path>).
  • The file is re-read within a minute when you change it.
Mistakes. A wallet, pool, worker, gpuN, failover or option line that cannot be read stops the miner with one line that names the line number and never prints your address, because those lines decide where your money goes. A mistake in a tariff, power supply, fee or other value is one note line, and the default is used.
