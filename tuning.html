Tuned per card

Two cards of one model often differ. Armadig finds each card's own best settings, once, while mining.

How the tune works

  • The first time a card runs a kernel, the miner tunes it while mining. The console says SAFE AUTO-TUNE: tuning this card once for this kernel ... mining continues.
  • Shares found during the tune count normally. Points are scored by the rate the pool would credit; a point with any error or failed self-check is thrown away.
  • A tune is bounded: about 20 minutes per card and kernel on the first run, usually much less. The console shows the time left.
  • The winner must beat the built-in starting point in fresh paired measurements, otherwise the starting point is kept.
  • It changes launch settings only: never core clock, voltage or power limit.
armadig-miner - first start of a card
SAFE AUTO-TUNE: tuning this card once for this kernel ... mining continues
SAFE AUTO-TUNING: current hashrate is not final
  0  RTX 4060Ti  Pearl   tuning   one-time card tune ... up to 17 min left

next start:
SAFE AUTO-TUNE CACHED

Console view. The numbers are illustrative, your rig will show its own.

The cache

The result is stored in autotune.json next to the program, so later starts use it at once. A card is tuned again automatically when a new release ships a different kernel for it, when the card's power limit changed, or when the clock watch finds the card's clock far below its reference (for example an overclock profile was removed). A new release starts from the previous release's tune and only runs a full search if a neighbour is clearly better.

armadig-miner.exe --autotune on       # default
armadig-miner.exe --autotune off      # built-in starting point, no tuning
armadig-miner.exe --autotune redo     # tune every card again now
armadig-miner.exe --tune-cache D:\tune\autotune.json

To reset a tune: run once with --autotune redo or delete autotune.json.

Memory clock (NVIDIA)

--mem-controlEffect
auto (default)Built-in per-model table: for some models and coins the memory clock is locked to a measured value, for others it is left alone.
noneThe miner does not touch memory clocks. Use this if you set memory clocks yourself (Afterburner, nvidia-settings, HiveOS OC).
MHZLock the memory clock of all selected cards to this value.

The lock is restored at a normal exit. It needs administrator / root; without it one line says so and mining goes on. AMD on Windows: --mem-control has no effect.

Temperature protection

Above --panic-temp that card pauses until it reads 5 C below. Defaults: 90 C on NVIDIA; AMD junction temperature pauses at 105 C and resumes at 100 C. --warning-temp (default 76) only colours the cell yellow. Other cards keep mining. It is a safety net, not a fan controller: keep your fan curve in place.

armadig-miner.exe YOUR_PEARL_WALLET YOUR_QTC_WALLET --warning-temp 72 --panic-temp 85
