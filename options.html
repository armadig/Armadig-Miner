Command-line options

Everything the miner accepts. In armadig.conf every option can be written without --, and the command line wins over the file.

Commands

armadig-miner mine     [options]                       mine on the selected cards
armadig-miner selftest --algo pearl|qtc [--gpu LIST]   exactness self-test, then exit
armadig-miner bench    --algo pearl|qtc [--gpu LIST]   same gate, no hashrate
armadig-miner --list   [--gpu LIST]                    what each card would run; no GPU work
armadig-miner --help | --version

There is no option to change or redirect the dev fee. The program has no core-clock, voltage, memory-offset or fan option; it changes only the power limit.

One line, no config file (HiveOS / RaveOS flight sheet)

Everything armadig.conf holds can go on the command line in ONE line, in any order, with or without --. Put it into "Extra config arguments" (HiveOS) or the miner's arguments field (RaveOS). Nothing has to be written to disk.

armadig-miner PEARL_ADDRESS QTC_ADDRESS platinum,1200w 6.50 rub 23-07 9.65 rub 07-23
You writeThe miner takes it as
A Pearl or QTC address (ADDRESS.rig1 sets the worker name too)the payout address of that coin
any, fastest, kryptex, luckypool, herominersthe pool choice
host:port, stratum+tcp://host:portyour pool (with two coins write pearl-pool=host:port or qtc-pool=host:port)
bronze silver gold platinum titanium, 750w, 1.2kwpower supply class and rated watts
a price 6.50, a currency rub eur usd or $ €, hours 23-07a tariff zone (up to 3; one price with no hours = the whole day)
0,1the GPUs to use (5 usd is a price, 5 alone is GPU 5)
fixed, power 80%, mem-control none, worker rig1the same as the -- option of that name
  • The command line wins over armadig.conf, setting by setting. Tariffs on the command line REPLACE all tariff zones of the file.
  • No tariff anywhere: no electricity cost is used; coins are chosen by revenue.
  • A word the miner cannot place is shown as a plain note and ignored. A mistyped address or an unfilled %WAL% template is shown as a red note and not used; its value is never printed.
