# Armadig

GPU miner for **Pearl (PRL)** and **Quantus (QTC)**. Closed-source freeware, 0.75 % work-based dev fee on each coin (shown in the start banner).

- Two bare arguments are wallets: `armadig <pearl-wallet> <quantus-wallet>`
- One window and one process for all cards; each card mines the coin that pays best
- Profit mode: tariff + currency in a config file, best power limit per tariff zone
- One-time per-card tune, cached

Downloads: see **Releases**. Site: https://armadig.com. Telegram: https://t.me/armadigminer
