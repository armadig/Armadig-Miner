Supported cards and measured rates

NVIDIA from Turing to Blackwell, AMD RDNA2 to RDNA4. All GPU code is built into the program: you need only the normal graphics driver.

armadig-miner --list shows what would run on each of your cards. A card that is not supported is refused with a line that names the reason; the miner never silently runs a wrong kernel.

Cards of a supported family that we have not measured start from a generic point, and auto-tune then finds the card's own best settings. For the models we measured the program carries a tested starting point.

CMP 90HX: at start the miner measures the card's int8 tensor rate. An unlocked card mines Pearl; a locked card is refused for Pearl with a line that names the measured rate, and can still mine QTC.
